# Bible Advisor

**Every answer leads to Jesus.**

Bible Advisor is a free, offline-first Bible app for Android, built as a Progressive Web App (PWA). Tell it how you feel or what you face, and it shows Bible verses that speak to it, always leading to Jesus Christ, the Word (John 1:1, 14).

- 100% free: no account, no ads, no tracking, no paid APIs, no backend.
- Installs straight from Chrome on Android ("Add to Home screen") and works fully offline after the first load.
- Plain HTML, CSS and JavaScript (ES modules). No framework, no build step needed to run it.

## Features

| Screen | What it does |
| --- | --- |
| **Home** | Greeting by time of day, Verse of the Day (389 verses, about 40% from the Gospels), "How are you feeling today?", continue reading, reading streak, plan progress, links to Meet Jesus and Plans. |
| **Feelings** | 21 moods. Each opens a full-screen swipe-up feed of 13 to 14 hand-picked verses, each with a plain-English reflection and a one-line prayer. Card 1 is always "What Jesus says". Sad, Lonely, Grieving, Hurt and In pain end with a crisis-help card. |
| **Ask** | Offline topic engine: 75 topics with keyword and synonym maps. If no topic matches, it searches the whole Bible and shows the top 20 verses. Crisis phrases show help first. |
| **Bible** | All 66 books, Old and New Testament tabs, chapter grid, red letters for the words of Jesus, highlights (4 colours), notes, save, copy, share as image, font size, KJV / Easy English toggle, last position remembered, whole-Bible search grouped by book. |
| **Meet Jesus** | Who He is, His "I am" sayings, parables, miracles, the Sermon on the Mount, the cross and the resurrection, plus "How to know Jesus". |
| **Plans** | Gospel of John (21 days), Life of Jesus (30), Psalms of comfort (14), Proverbs (31), New Testament (90). Daily check-off, progress bar and streak. |
| **Saved** | Saved verses, highlights and notes, filtered by feeling or book. Export and import a JSON backup. |
| **Share** | A 1080×1350 image in Parchment, Navy or Olive, shared through the Web Share API or downloaded. |
| **Settings / About** | Theme (system, light or dark), translation, text size, optional daily reminder, offline status, reset. Copyright and privacy notes. |

## Bible text and copyright

Both bundled translations are in the **public domain**:

- **KJV**: King James Version (1769 text), from eBible.org `eng-kjv2006`.
- **Easy English**: World English Bible (WEB), from eBible.org `engwebp` (66 books, uses "the LORD"). "World English Bible" is a trademark of eBible.org.

No copyrighted translation (NIV, NLT, ESV and so on) is included. The **red letters** come from the `\wj` (words of Jesus) markup in the eBible.org source files.

The reflections, prayers, topic summaries and Meet Jesus notes were written fresh for this app. They are not Scripture. Content files hold **references only**, never quoted text: the app always shows the exact bundled text, so a verse cannot be misquoted.

## Run locally

A service worker needs `http://localhost` or HTTPS, so use a small web server rather than opening the file directly:

```bash
python3 -m http.server 8080
# or: npx serve .
```

Then open <http://localhost:8080>.

## Editing content

Edit `data/moods.json`, `data/topics.json`, `data/votd.json` or `data/jesus.json`. Then run:

```bash
node tools/build.mjs
```

This **validates every scripture reference** against both the KJV and WEB text, plus the content rules: at least 12 verses per mood, card 1 is "What Jesus says", reflections are 1 to 3 sentences, at least 60 topics and at least 365 daily verses. **The build fails loudly** if any reference is missing:

```
✗ moods.json › anxious #6 (Psalm 94:99): "Psalm 94:99" does not exist in KJV
Build failed: fix the content errors above.
```

When it passes, it regenerates `precache-manifest.js` with a new version hash, so installed apps pick up the change.

To print every curated verse's text next to its reflection for a review read, run `node tools/validate.mjs --print`.

Other scripts:

| Command | Purpose |
| --- | --- |
| `node tools/build-plans.mjs` | Regenerate `data/plans.json` |
| `node tools/make-icons.mjs` | Render PNG icons from `icons/logo.svg` (uses Playwright's Chromium) |
| `node tools/build-bible.mjs <kjv-dir> <web-dir>` | Rebuild the Bible JSON from eBible.org USFM (`eng-kjv2006_usfm.zip`, `engwebp_usfm.zip`) |
| `node tools/smoke.cjs http://localhost:8080/ <out-dir>` | Playwright smoke test with screenshots |

## Deploy free to GitHub Pages

1. Push this folder to a GitHub repository. The app files must be at the repository root (or in `/docs`).
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick your branch (for example `main`) and the `/ (root)` folder, then click **Save**.
4. After a minute your app is live at `https://<user>.github.io/<repo>/`.

All paths in the app are relative, so it works from a sub-folder like `/<repo>/`. GitHub Pages serves HTTPS, which service workers require.

**Netlify** works the same way: drag the folder onto <https://app.netlify.com/drop>, or connect the repository with no build command and publish directory `.`.

## Install on Android

1. Open the app's URL in **Chrome** on your Android phone.
2. Wait a few seconds on the first visit. The app saves itself and the whole Bible (about 2.5 MB) for offline use.
3. Tap Chrome's **⋮** menu, then **Add to Home screen** (or **Install app**).
4. Open **Bible Advisor** from your home screen. It runs full screen and works with no internet.

You can check offline status in **Settings → Offline**: it shows when both translations are fully saved.

## Package an APK with PWABuilder

1. Deploy the app to an HTTPS URL first (GitHub Pages or Netlify).
2. Go to <https://www.pwabuilder.com> and enter your app's URL.
3. PWABuilder checks the manifest, service worker and icons. This app ships everything it needs: name, short name, `id`, `start_url`, `scope`, standalone display, theme and background colours, and 192, 512 and maskable 512 icons.
4. Click **Package for stores → Android**. Keep the defaults (Trusted Web Activity), or set your own package ID, for example `org.example.bibleadvisor`.
5. Download the ZIP. It contains a signed `.apk` for side-loading and testing, an `.aab` for Google Play, and `assetlinks.json` plus your signing key. **Keep the signing key safe.**
6. To remove the browser address bar inside the APK, upload `assetlinks.json` to `/.well-known/assetlinks.json` on your site. On GitHub Pages this needs a custom domain or a `<user>.github.io` user site, because the file must sit at the domain root.

## Daily reminder

The reminder is created on the phone, and nothing is sent anywhere. It uses Periodic Background Sync, which Chrome on Android supports for **installed** apps. Android decides the exact moment, so the reminder can arrive a little after the chosen time. On browsers without this feature, the setting explains that reminders are not available.

## Ask: optional AI later (askProvider)

`js/ask-provider.js` defines a small `askProvider` interface. The app ships only the offline engine. A future provider can be plugged in with `setAskProvider({ id, name, ask(question, { tr }) })`. It must return **references only**, so the app can keep showing the exact bundled text. See the comment block at the top of that file.

- Lighthouse (mobile, simulated 4G): Performance 98, Accessibility 100, Best Practices 100, SEO 100. First Contentful Paint 1.7 s, Largest Contentful Paint 2.0 s.
- Chrome reports no installability errors. axe-core shows no violations on any screen in light or dark mode.
- Colour contrast is at least 4.5:1 for text. Stone (#8A8278) is darkened to #6B645B for muted text on parchment. In dark mode, Jesus' words use a light tint of crimson so they stay readable on navy.
- Respects `prefers-reduced-motion`. Touch targets are at least 44 px. Works from 360 px wide.
